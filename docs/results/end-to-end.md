# Сквозной замер: время синхронизации и объём данных

Сценариев на режим: 10 (5 в базовой конфигурации и 5 с 20 клиентами, 20 профилями и офлайном по 6 операций), перед замером — прогревочный прогон. Клиент — HTTP-запросы `/sync` по loopback к серверу на Kestrel, PostgreSQL 16 в Docker. Машина: Microsoft Windows 10.0.19045, логических процессоров: 8, .NET 8.0.32. Время на стороне сервера и метода — из заголовка `Server-Timing`.
